PARA NAJU — primeira reconstrução

Arquivos:
- index.html: estrutura das telas
- style.css: aparência e animações
- script.js: navegação e revelação da carta por toques
- assets/: imagens extraídas da gravação de referência

Para testar: abra index.html no navegador.
Para publicar: envie o conteúdo desta pasta para a raiz de um repositório GitHub e ative GitHub Pages em Settings > Pages > Deploy from a branch > main > /(root).

Nota: esta é a primeira versão funcional baseada nos quadros da gravação 512x852. A carta revela os parágrafos um por um ao tocar em “Toque para continuar”.
